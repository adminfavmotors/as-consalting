# A.S. Consulting — готовый статический сайт

Польскоязычный сайт для Andrzej Sadowski. HTML, CSS и JavaScript; без runtime-зависимостей, CDN и внешних запросов при просмотре.

Текущая версия — переработанный автомобильный дизайн: Saira / Barlow, холодная графитовая палитра, фотография на всю ширину, компактная навигация и предметные заголовки. Основания решений и изученные референсы Audi / Porsche описаны в `design/DESIGN.md`. Первая версия сохранена в `design/archive/editorial-v1.zip`.

## Что реализовано

- Самостоятельные страницы, адаптивная вёрстка, общее меню и подвал.
- Мобильное меню: закрытие по Escape, клику вне меню и уходу фокуса.
- FAQ на нативных `details` / `summary`; работают без JavaScript.
- Кнопки обращения из услуг с автоматическим выбором темы в контактах.
- Телефонные и почтовые ссылки.
- Форма подготовки письма: проверка полей, сводка ошибок со ссылками, предпросмотр, возврат к редактированию, открытие почты, копирование с запасным ручным вариантом.
- Форма ничего не отправляет на сервер. Пользователь видит это объяснение и отправляет письмо из своей почты. Серверный обработчик не требуется для текущего сценария.
- Локальные шрифты, оптимизированная фотография WebP с JPEG fallback, favicon.
- Уникальные title/description и Open Graph текстовые метаданные.
- Фокус с клавиатуры, переход к основному содержимому, подписи полей, уменьшение движения, печатные стили.

## Сборка и проверка без запуска

Нужен Node.js 24.x. Установка npm-пакетов не требуется.

```powershell
npm run build
npm run check
```

Обе команды завершаются после работы. Сервер не запускают, портов не открывают.

Все страницы уже собраны в `dist`. Сайт рассчитан на размещение в корне домена; ссылки имеют вид `/oferta/audyty/`, ресурсы — `/assets/…`. Для просмотра нужен HTTP-хостинг; прямое открытие HTML через `file://` не поддерживается.

## Размещение на Vercel

1. В Vercel выберите **Add New → Project** и импортируйте GitHub-репозиторий `adminfavmotors/as-consalting`.
2. **Root Directory** — корень репозитория (`./`), **Framework Preset** — **Other**, production-ветка — `main`.
3. Настройки уже заданы в `vercel.json`: **Build Command** — `npm run build && npm run check`, **Output Directory** — `dist`, установка зависимостей отключена. Переменные окружения для запуска не нужны.
4. Нажмите **Deploy**. Vercel выдаст адрес проекта на `vercel.app`. Последующие push в `main` будут обновлять сайт при подключённой Git-интеграции.

Публикуется только содержимое `dist`. Вложенные страницы открываются напрямую и при обновлении браузера. `cleanUrls` и `trailingSlash` нормализуют адреса; неизвестные пути обслуживает собственная `dist/404.html` со статусом 404. Общий rewrite на главную не требуется.

Для собственного домена откройте **Settings → Domains**, добавьте домен и у регистратора внесите именно те DNS-записи, которые покажет Vercel. После проверки DNS Vercel выпустит HTTPS-сертификат. Переносить регистрацию домена для этого не требуется. DNS старого сайта изменяйте после проверки новой версии.

После деплоя проверьте `/`, `/oferta/audyty/`, `/kontakt/?temat=Audyty` и любой несуществующий вложенный адрес, например `/oferta/brak-strony/`: он должен вернуть 404 с оформлением сайта и рабочим меню. Также проверьте мобильное меню и подготовку письма. Форма открывает почтовую программу посетителя, серверной отправки писем нет.

Документация: [настройки vercel.json](https://vercel.com/docs/project-configuration/vercel-json), [статическая страница 404](https://vercel.com/kb/guide/custom-404-page), [подключение домена](https://vercel.com/docs/domains/working-with-domains/add-a-domain).

## Следующий этап: локальный запуск

По просьбе пользователя сервер на этапе создания не запускался. Перед запуском отдельно проверить занятые порты и выбрать свободный. Затем проверить страницы в браузере на desktop и mobile, клавиатурную навигацию и форму.

После выбора окончательного домена можно добавить canonical, абсолютный OG image URL, sitemap и согласовать redirects старых языковых страниц. Эти настройки не требуются для запуска на адресе Vercel.

Куки, политики и правовые элементы намеренно не добавлены. Текущая версия — польская.

## Изображение

Иллюстративная автомобильная фотография создана для проекта. Оптимизированные версии уже включены. При необходимости их можно повторно получить из `design/automotive-original.png`, передав путь к установленному `sharp`:

```powershell
node scripts/prepare-images.mjs 'C:/path/to/node_modules/sharp'
```

`sharp` нужен только для повторной обработки изображения, не для сборки или работы сайта.
